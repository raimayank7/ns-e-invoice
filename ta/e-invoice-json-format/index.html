இ-இன்வாய்ஸ் JSON ஃபார்மேட் (INV-01) விளக்கம்

இந்த மேக்கர் டவுன்லோட் செய்யும் ஃபைல், அரசின் இ-இன்வாய்ஸ் ஸ்கீமாவான FORM GST INV-01 (வெர்ஷன் 1.1) படி இருக்கும். இதைக் கையால் எடிட் செய்ய வேண்டிய அவசியம் இல்லை; ஆனால் போர்ட்டல் பிழை காட்டும்போது, உள்ளே என்ன இருக்கிறது என்று தெரிந்தால் உதவும்.

ஃபீல்டுகள் பின்பற்ற வேண்டிய விதிகள்

  • இன்வாய்ஸ் நம்பர்: 16 எழுத்துகள் வரை, எழுத்துகள், இலக்கங்கள், / மற்றும் - மட்டும்; 0, / அல்லது - இல் தொடங்கக் கூடாது. நிதியாண்டில் உங்கள் GSTIN-க்கு தனித்துவமானதாக இருக்க வேண்டும்.
  • தேதிகள்: DD/MM/YYYY, எதிர்காலத்தில் இருக்கக் கூடாது.
  • GSTIN-கள்: சரியான செக் எழுத்துடன் 15 எழுத்துகள். உங்களுடையதும் வாங்குபவருடையதும் வேறுபட வேண்டும்.
  • பின் கோடு: மாநிலத்துடன் பொருந்தும் 6 இலக்கங்கள். இடம் (Loc): குறைந்தது 3 எழுத்துகள்.
  • HSN: 6 அல்லது 8 இலக்கங்கள் (99-இல் தொடங்கும் கோடுகள் சேவைகள், IsServc = Y, யூனிட் தேவையில்லை).
  • யூனிட்: NOS, PCS, KGS, LTR, MTR, BOX, SET போன்ற GST யூனிட் கோடு. வேறு சொற்கள் OTH ஆக அனுப்பப்படும்.
  • தொகைகள்: ஐட்டம் வரிகள் மொத்தங்களுடன் சரியாகக் கூட வேண்டும். போர்ட்டல் மிகச் சிறிய ரவுண்டிங் வேறுபாட்டை மட்டுமே அனுமதிக்கும்; ரவுண்ட் ஆஃப் தனி ஃபீல்டில் போகும்.
  • ஏற்றுமதிகள்: வாங்குபவர் GSTIN "URP", மாநில கோடும் சப்ளை இடமும் 96, பின் கோடு 999999. வரி கட்டிய சப்ளைகள் (EXPWP, SEZWP) மாநிலத்துக்குள்ளேயே என்றாலும் IGST பயன்படுத்தும்; LUT-இன் கீழ் உள்ளவை (EXPWOP, SEZWOP) ஒவ்வொரு ஐட்டத்திலும் 0% GST கொண்டிருக்க வேண்டும்.
